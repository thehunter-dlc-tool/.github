## 🧰 Requirements

Before using the tool, ensure you have:

* A legitimate **Steam version** of **TheHunter: Call of the Wild**
* An active internet connection for metadata retrieval
* **.NET 7 Runtime** installed
* Appropriate access permissions for the game installation directory

---

## 🚀 Installation & Setup

1. Download the latest release.
2. Extract all files to a preferred location.
3. Launch the application.
4. Select your game installation directory.
5. Follow the on-screen instructions to scan and verify installed content.

## 💡 Tips

* Always back up your game files before making configuration changes.
* Keep the tool updated to ensure compatibility with the latest game patches.
* Use only official game installations obtained through authorized platforms.
* Re-run content verification after major game updates.
